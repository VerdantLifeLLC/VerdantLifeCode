# The Lattice Chronicles

An epic fantasy LitRPG series about two estranged brothers, Lex and Antho, the hidden System that rules their world, and the father who sealed their power away.

- **Book One: The Sorcerer's Reckoning** — `book1/chapters/`
- **Book Two: The Sorcerer's Legacy** — `book2/chapters/`

| File | What it is |
|---|---|
| `BIBLE.md` | Series bible: the System's rules, world, characters, secrets, chapter plans |
| `CONTINUITY.md` | Running ledger of levels, stats, skills and items per chapter |
| `ORIGINAL-OUTLINE.md` | The author's original outline both books grew from |
| `build.py` | Builds 6 x 9 in KDP paperback interiors (PDF) and Word files |
| `output/` | Built books |
| `fonts/` | EB Garamond, Cinzel and IBM Plex Mono (SIL Open Font License) |
